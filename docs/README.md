# Repository documentation assets

This directory is not the LCARS-WebUI user or API documentation. It holds historical
notes, generated documentation screenshots, and offline canon-recreation comparisons.

Start with one of these instead:

- [`../lcars-ui/docs/`](../lcars-ui/docs/) — maintained package guides and API reference.
- [The LCARS-WebUI wiki](https://github.com/darsrc/LCARS-WebUI/wiki) — task-shaped
  tutorials, recipes, and troubleshooting.
- [`../llms.txt`](../llms.txt) — the curated documentation index for coding agents and
  documentation tools (`../llms-full.txt` contains the indexed pages in one file).

The subdirectories here are supporting material:

- [`archive/`](archive/) contains retired, non-normative records.
- [`screenshots/`](screenshots/) contains captures of live, code-rendered examples.
- [`CANON_RECREATION/`](CANON_RECREATION/) contains offline visual comparisons used to
  document parity work; those images are never application UI assets.
